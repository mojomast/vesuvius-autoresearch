# Submission Package Template

This directory contains templates for reviewer-facing prize submission metadata. Do not commit hidden text, unapproved discovery images, raw data, or large generated outputs here.

A complete external submission package should include:

- generated image or probability output
- `metadata.template.json` filled with exact IDs and coordinates
- command that generated the output
- config and commit hash
- model weight checksum or training instructions
- scale-bar details for discovery imagery
- no-overlap statement for training and prediction regions

Coordinate public disclosure of any hidden text, full words, titles, or associated code with Scroll Prize before publishing.
